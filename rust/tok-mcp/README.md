# tok-mcp

The MCP server of the tok process language (stdio transport), for AI agents that model
processes: the tools `check`, `fmt`, `export` (BPMN, SVG, DMN, forms), `import` (BPMN and DMN
to tok, with the layout sidecar), `sim`, `eval` and `reference`, and the language reference
as resources `tok://reference/…`.

```
cargo install tok-mcp
```

The configuration of MCP clients is in `docs/mcp.md` of the repository.
